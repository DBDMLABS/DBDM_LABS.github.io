# DBDM Labs — GitHub Pages Website

Professional static website for DBDM Labs, designed around the supplied logo, CEO/office imagery and hero banner.

## Files
- `index.html` — complete landing page
- `styles.css` — responsive visual system
- `script.js` — mobile nav + appointment modal/demo form
- `assets/` — supplied DBDM Labs imagery

## Deploy to GitHub Pages
1. Create a GitHub repository, e.g. `dbdm-labs.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Open the generated GitHub Pages URL.

## Before production
Replace every `XXX` placeholder in `index.html`, especially:
- CEO name/title
- email, phone and office address
- LinkedIn, Facebook, WeChat, Google Business, WhatsApp and X links
- timezone / availability
- legal/privacy links if required

The appointment form is intentionally frontend-only. For real submissions, connect it to a form backend such as Formspree, Netlify Forms, a serverless function, Calendly, or your own API.

## Branding
The site uses the uploaded DBDM Labs visual assets and a dark navy / electric blue / orange visual language to match the logo.
